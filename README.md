# 🤖 CS6102 – Exploration in Artificial Intelligence Lab

This folder contains the complete set of Python programs and laboratory exercises for the course **Exploration in Artificial Intelligence .

## 📁 Laboratory Exercises Index

This repository is structured sequentially according to the official course syllabus:

| Ex. No. | Exercise Name | Core Libraries / Concepts Used |
| :---: | :--- | :--- |
| **1** | Student Marks, Percentage, Grade and Academic Performance | Python Basics, Operators |
| **2** | Electricity Billing System Using Conditional Statements and Loops | Control Flow (`if-else`, loops) |
| **3** | Menu-Driven Student Information Management | Functions, Core Logic |
| **4** | Student Record Management Using Lists, Tuples, Dictionaries, Files and CSV | File I/O, Python Data Structures |
| **5** | IoT Sensor Data Analysis Using NumPy | `numpy` Arrays & Math Operations |
| **6** | Analysis of Student Dataset Using Pandas Series and DataFrame | `pandas` DataFrames & Series |
| **7** | Data Cleaning and Exploratory Data Analysis Using Pandas | `pandas` Data Cleaning |
| **8** | Data Cleaning, Exploratory Data Analysis and Visualization Using Pandas and Matplotlib | `pandas`, `matplotlib` |
| **9** | Data Visualization Using Matplotlib | Data Plotting & Graphing |
| **10** | Prompt Design and Evaluation Using Generative AI | GenAI, Prompt Engineering |
| **11** | Role-Based, Zero-Shot, One-Shot and Few-Shot Prompting | LLM Prompting Paradigms |
| **12** | AI-Assisted Generation of Technical Content and Python Programs | Automated Code Generation |
| **13** | AI-Powered Study Assistant Using Python and Generative AI | Python + Generative AI Integration |
